# PC VPN Bridge

[English](README.md) | [Русский](README.ru.md)

Android-приложение для туннелирования всего трафика смартфона через прокси-сервер вашего компьютера (SOCKS5 / HTTP CONNECT).

## 📖 Инструкция по настройке и подключению

### Шаг 1. Включите общий доступ в VPN-клиенте на ПК

Чтобы смартфон мог подключаться к прокси вашего компьютера по Wi-Fi, на ПК необходимо разрешить подключения из локальной сети.

#### 🔹 Пример: Karing (Рекомендуется)
1. Откройте приложение **Karing** на ПК.
2. Перейдите в **Настройки** ⚙️.
3. Включите пункт **«Allow LAN»** (*Разрешить подключения из локальной сети*).
4. **Порт по умолчанию**: Karing использует порт **`4066`** (именно он установлен по умолчанию в приложении PC VPN Bridge).

#### 🔹 Другие программы на ПК (v2rayN, Clash, Hiddify, NekoBox)
- В настройках программы включите тумблер **Allow LAN** / **Разрешить LAN**.
- Посмотрите порт SOCKS5 или HTTP прокси (например, `10808`, `7890`, `1080`).

---

### Шаг 2. Включение `.local` имен на Windows (Необязательно)

Если вы хотите подключаться по имени компьютера (например, `matebook.local` или `pc.local`) вместо постоянного ввода IP-адреса (`192.168.x.x`):

1. Операционной системе Windows требуется служба **Apple Bonjour** для рассылки mDNS-имен по сети Wi-Fi.
2. Скачайте и установите **[Bonjour Print Services for Windows (Официальная ссылка Apple)](https://support.apple.com/kb/DL999)** (*Мастер установки принтера Bonjour* / *BonjourPrinterSetup.exe*).
3. После установки ваш ПК будет мгновенно откликаться на `.local` запросы со смартфона за ~10 мс.

> 💡 *Примечание: Если вы вводите чистый IP-адрес ПК (например, `192.168.1.50`), устанавливать Bonjour не обязательно.*

---

### Шаг 3. Подключение смартфона

1. Установите **PC VPN Bridge** на Android смартфон.
2. Введите **Имя компьютера** (например, `matebook.local`) или **IP-адрес** (например, `192.168.1.50`).
3. Проверьте **Порт** (по умолчанию `4066` для Karing).
4. Нажмите **Подключить**!

## ✨ Ключевые возможности

- ⚡ **Автоопределение протоколов**: Автоматически распознает **SOCKS5**, **HTTP CONNECT** или **Direct TCP** на порту ПК.
- 🌐 **Нативная поддержка `.local` имен (mDNS RFC 6762)**: Отправляет широковещательные UDP-запросы по сети Wi-Fi для мгновенного определения IP-адресов ПК за 10 мс.
- 📺 **Полная поддержка YouTube 4K и медиа-трафика**:
  - **Сегментация по MSS 1460 байт**: Крупные видеоданные автоматически нарезываются на стандартные валидные пакеты под лимит MTU 1500 интерфейса TUN Android.
  - **Защищенный двухрежимный DNS**: Нативный резолв доменов через Google Public DNS `8.8.8.8:53` в обход подмены DNS со стороны провайдеров.
- 🛡️ **Защита от вылетов при быстром переключении**:
  - Атомарная синхронизация сокетов через `Mutex`.
  - Мгновенное переиспользование локальных портов (`reuseAddress = true`).
  - Потокобезопасная последовательная передача TCP-пакетов без нарушений порядка.
- 📊 **Встроенная консоль диагностики в реальном времени**: Трансляция логов подключения, DNS-запросов и статусов туннелирования прямо в интерфейсе приложения.
- 🎨 **Современный дизайн на Jetpack Compose (Material 3)**: Мультиязычный интерфейс (Английский и Русский), Тёмная и Светлая тема, адаптивная иконка приложения.

## 📱 Сборка и установка

### Требования
- Android 8.0 (API Level 26) или выше
- JDK 17 / Kotlin 1.9+
- Android Studio или Gradle CLI

### Сборка APK из исходников

```bash
# Клонирование репозитория
git clone https://github.com/elkatigr1999-commits/PCvpn-bridge.git
cd PCvpn-bridge

# Сборка Debug APK
./gradlew assembleDebug
```

Собраное приложение будет доступно по пути: `PCVPN-Bridge-v1.0.apk`.
